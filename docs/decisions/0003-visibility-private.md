# 0003: Keep the repository private

Date: 2026-11-20
Status: superseded by 0016

## Context
Visibility controls who can see the code, issues and releases. The skill set is in early development.

## Decision
The repository is private until the first release.

## Consequences
Only invited collaborators have access. On a free personal account, GitHub does not enforce branch rules on private repositories; repo-governance will record the fallback. Making it public is a repo-governance action with its own record.
